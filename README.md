# ConfigProcessScript

基于 [Echsfxy 普通版 Mihomo 脚本](https://github.com/echs-top/proxy)，叠加个人规则与功能。

## 使用

将下面的脚本地址添加到 Bettbox 的订阅覆写脚本中：

```text
https://raw.githubusercontent.com/ValoHalo/ConfigProcessScript/main/Script/mihomoScript.js
```
